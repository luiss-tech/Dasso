# Página

Arquitectura backend esqueleto para un proyecto PHP/MySQL en XAMPP.

## Estructura principal

- `public/` - punto de entrada web, API y assets públicos.
- `src/` - lógica de backend dividida en Core, Controllers, Models, Services, Helpers y Middleware.
- `resources/views/` - plantillas y componentes HTML.
- `storage/logs/` - archivos de log.
- `public/uploads/` - directorio para archivos subidos.

## Comandos

- `composer install`
- `composer start`

## Recomendación

Instalar dependencias y ejecutar con servidor PHP o XAMPP.
